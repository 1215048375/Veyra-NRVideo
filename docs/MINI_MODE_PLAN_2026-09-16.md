# 日常侧栏与 MINI 模式（2026-09-16）

用户要求日常模式具备专业模式左侧功能栏，新增仅侧栏和进度条的MINI模式。共用原视频、采集、图片、列表、PS5入口，增加侧栏“模式”菜单，提供日常/专业/MINI、最小化/关闭。日常去掉底栏重复文件入口，为新增侧栏腾出空间；窄窗口采用紧凑列表按钮。图片打开不再自动切专业模式。诊断和导出完整配置入口仍可切到专业模式使用。

MINI保留画面、68DIP侧栏、28DIP进度区，隐藏其他主窗口面板及底部工具。最低480×440；侧栏空白可拖动窗口，模式菜单保证可退出。F11仍为现有全屏行为，退出恢复所选模式。原画面对比/字幕叠加、点击暂停、方向键跳转、图片滚轮翻页继续使用同一引擎。MINI与其他模式切换即时，日常/专业保留动画；切换不改变增强配置、不重新打开媒体。启动仍为日常模式，小MINI窗口关闭时保存至少720×540的启动尺寸，避免旧偏好校验失败。
