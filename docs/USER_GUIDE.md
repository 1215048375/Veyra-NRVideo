# Veyra 本机使用 — 日常 / 专业双模式

双击项目根目录 `Veyra.cmd`。实际程序为 `out/build/x64-release/veyra.exe`；本机 runtime / shader 路径在构建时绑定，不要移动项目目录。这不是可公开分发的安装包。

## 两种界面

启动始终进入日常模式。上方全部留给视频，底栏上行显示时间和文件名，下行直接提供打开、采集卡、最近文件、增强总开关、SR超分、停止/播放、音量、字幕、全屏、专业模式、最小化和关闭。没有隐藏这些功能的齿轮菜单。窄窗口收起部分文字、保留全部图标入口；悬停可查看名称。图标使用免费可商用的 Lucide，许可证保留在 `assets/icons/lucide/LICENSE`。

底部“专业模式”展开专业工作台：左侧图标栏提供视频、采集、图片和最近文件，右侧四个标签集中增强、补帧、预设和导出；下方显示真实处理尺寸和最近NR阶段耗时。专业模式顶部提供预设快捷选择。字幕菜单和软件内下拉选项共用圆角毛玻璃弹层，橙色勾选标记表示当前值；方向键选择、回车确认、Esc取消，Tab/Shift+Tab取消并移到相邻控件。长列表支持滚轮和首尾键。Windows文件选择对话框保留系统操作方式。

展开和收起采用240毫秒动画，连续反向点击从当前展开位置返回。两种模式保留同一个视频宿主和播放会话，不重新打开文件，不套用另一套画质参数。专业模式的对比状态会记住，但日常模式恢复正常增强显示。小窗口通过“参数”按钮打开右侧抽屉。窗口空白处可拖动，边缘可调整尺寸；日常模式底部右侧提供最小化和关闭。

增强总开关关闭时真正旁路NR、SR与补帧，开启后恢复配置。关闭期间修改数值只保存待启用配置；直接开启专业NR或超分开关，也会开启总增强。NR和超分开关点击后立即请求生效，无需再点“应用整套设置”，数值草稿不会阻挡它们。界面显示“正在应用”时，以右栏已应用版本为准；失败会恢复实际状态。总增强正在切换时，新的整套参数提交暂不执行，草稿保留。

控制区使用 Windows 11 Desktop Acrylic：可透出窗口下方桌面或其他软件的模糊颜色，文字和按钮单独绘制。没有固定彩色渐变，也不会截取桌面再贴回界面。视频区始终不透明，没有打开媒体时纯黑；全屏关闭桌面材质，保留视频、字幕和可隐藏控制条。系统关闭透明效果、使用高对比度或不支持 Desktop Acrylic 时，会采用系统/实色回退，不会自动更改你的 Windows 设置。独立采集设置窗口仍为普通深色界面。

## 播放和参数

1. 点“打开视频”或拖入 H.264/HEVC 视频；PNG/JPEG图片自动进入专业模式。Ctrl+O打开文件。空格在视频/主窗口焦点下播放、暂停；输入框保留正常输入。
2. “DLSS 超分辨率 · 4K”将底图按比例放大到3840×2160范围，尺寸取偶数。16:9输出3840×2160；4:3输出2880×2160；已达到边界的画面跳过SR，避免拉伸。播放、图片保存和视频导出共用此尺寸规则。“实时NR档”保留该底图，约1080p内部NR的变化由GPU回填。状态显示输入、底图、NR、光流、FG与输出实际尺寸。
3. 取消“实时NR档”可选原生NR，性能成本更高，不承诺原生4K60。“补帧”配合2X/3X/4X选择，倍率表示每对源帧的总时间格数；无效生成或reset不会计作有效补帧。
4. 专业模式“增强”提供7项NR参数及5项变化量参数。可滚动查看，悬停数值框查看范围；数值框修改后点“应用整套设置”，滑杆采用120毫秒去抖。期望与已应用版本固定显示，真实帧边界整套应用，失败回滚；切换面板会保留草稿并取消尚未发出的延迟提交。参数修改不重新打开视频或归零进度。修改尺寸/光流会有有界资源重建。
5. 肤质结构、风格、自动遮罩、画面内UI修正属于实验参数。当前合成样本未观察到肤质/UI修正的像素变化，不能保证实际效果；风格和自动遮罩已观察到变化。
6. 预设支持新建、复制当前、重命名、删除、设默认、恢复内建默认，保存在 `runtime_local/user-presets.v1`。配置损坏会保留原文件并报错，不静默覆盖。
7. 光流三档为性能/平衡/质量；界面记录实际应用档。30/50/60模式用于识别内容节奏，不会把源时间轴重采样成指定帧率。静止画面不能确认较低内容帧率。
8. 进度条定位，Space播放/暂停；F11、Alt+Enter、视频区域双击或全屏按钮切换，Esc退出全屏。全屏只展示铺满显示器的视频和字幕，控制条覆盖在底部；鼠标离开控制条并静止约1.6秒后，操作条与鼠标隐藏，移动鼠标会唤回。参数面板在全屏隐藏，退出恢复原窗口与模式。设备丢失会停止并报错，重新打开源恢复，不是无缝恢复。

## 图片尺寸与预览缩放

图片支持竖图、长图和奇数尺寸。超出单张GPU纹理能力或较大面积的图片自动分块增强，保留完整尺寸用于PNG/JPEG保存；状态会标明分块NR，其上下文不等同整图NR。实际可用尺寸仍受解码器、内存与GPU能力限制。图片不运行光流或帧生成。

专业模式：鼠标悬停画面后滚轮缩放（以鼠标位置为中心），按住中键拖动，右键恢复适应窗口。切回日常模式或打开新媒体时恢复适应窗口。缩放只影响预览，不重启增强，也不改变保存/导出尺寸。大图缩放从完整增强结果取景。

## 手动保护画面中的 UI / 字幕

专业模式 → 增强 → “框选区域”，在画面上按住左键拖动，最多保存4个区域；Esc取消当前框选，“清除区域”删除全部。保护区域随画面坐标缩放，可随预设保存；切换媒体来源会清空，避免把上个画面的框误用到新内容。

“NR保护区域”仅抑制这些区域的NR改动，框内的背景也会一起保留。它不是自动识别HUD，也不保证SR超分或帧生成不改变该区域。合成动态背景、固定HUD和字幕更替已做像素验证；自然素材效果仍需观察。原有“UI修正 · 未证实”是模型实验参数，与手动保护不同；私有UI资源尚未接入产品。

## 对比、性能与诊断

- 专业模式按住V或“按住原图”临时查看原图；可用“原图/增强切换”和“分屏拖动”，并选择输入原画或增强前底图作为参考。对比显示同一源帧的GPU参考，生成帧没有天然原图时明确使用真实帧对比。
- “性能/诊断”中GPU timestamp与CPU解码、提交、等待、Present分开。实际提交频率不等同物理屏幕扫描；没有测到的项目显示未测，不以源帧率乘倍率代替。
- 诊断包括真实失败码、阶段/尺寸/帧身份与运行时标识；相同问题合并计数、固定上限。复制前可预览脱敏文本；不自动上传任何内容。
- 同名 UTF-8/UTF-16LE `.srt` 在FG后的透明字幕层显示；字幕按钮可开关、载入外部SRT或调整字号。暂不解码内嵌字幕，也不烧录字幕进导出文件。
- 音量与静音只控制Veyra自己的音频，不修改Windows总音量。无音轨时控件禁用。采集音量依设备图是否提供音频控制，实际能力会反馈。

## 图片与视频导出

- 专业模式“导出”页的“保存当前图片 / 视频帧”保存当前真实源帧的增强PNG/JPEG。不会覆盖已有文件。
- Ctrl+E进入专业导出页。选择新MP4路径和H.264/HEVC后启动独立作业，观看继续。启动时冻结完整已应用设置；后续播放器调参不改变该作业。实时NR档不降低导出分辨率，4K输入默认原生4K NR。编码使用D3D12 NVENC input/fence，CPU只接压缩码流。
- 页内提供暂停、继续、取消及“优先观看”。优先观看在完整源帧之间给导出让出时间，保留全部源帧；同一GPU仍可能争用，不保证所有4K组合同时实时。封装/验证期间不能暂停，只有子进程确认成功才显示100%。
- 可查看作业ID、冻结设置版本、源帧、有效生成、CFR占位与编码计数。日常模式也显示任务状态入口，点击返回专业导出页。
- 默认保留第一条可封装MP4的音轨；不兼容编码明确拒绝，不静默丢音轨。无多音轨选择或音频转码。
- CFR输出支持2X/3X/4X；缺失/无效生成及尾部保持帧明确记为Hold。先采样最多120帧时间戳，只存元数据，再从头读取导出；全程继续验证时间轴，不均匀时间戳会拒绝。
- 对量化短片，原始精确帧率可能无法唯一推断；优先使用与时间戳一致的标准标称帧率，否则选择一致的标准候选，再尝试非标准标称帧率，日志记录声明值和候选值。不宣称恢复了唯一原始帧率。
- 播放器“停止”只停止当前来源；导出通过专业页“取消导出”取消。正常退出时如果有活跃作业，会提示取消并退出或返回继续。已产生的 `.partial` 保留诊断，不改名成成功文件。预检查即失败时可能还没创建partial。重新导出使用新名称，不支持断点续编。

## 采集卡与边界

日常模式直接点底部“采集”图标，专业模式点左侧采集图标，选择真实视频设备、实际格式和HDMI音频输入。先NR开、FG关检查视频声音，再选补帧倍率。补帧需要等待下一源帧，不能消除采集卡固有延迟。当前修复版本的实卡验收由用户完成，本轮未占用采集卡。

仅Windows x64/NVIDIA/SDR，偶数尺寸最高3840×2160；HDR不支持。Depth provider未实现，当前为NVOF motion + confidence门控，不等同游戏原生深度/运动向量。短测不证明长期稳定、所有采集卡兼容或画质优于其他产品。实际屏幕扫描/光子延迟、多屏物理DPI穿越尚未测量。专有runtime分发权未解决，不打包、上传或发布DLL/SDK。

窗口尺寸、位置、音量、字幕等保存在独立UI偏好中；只保存成功应用的画质。损坏的原配置保留，不静默覆盖。程序每次重启仍默认日常模式。
