# 文件播放倍速（2026-09-18）

用户要求 0.2×～3×，日常、专业、MINI 都能看到入口。默认 1×，会话内跨文件/列表和模式切换保留；左栏按钮和全屏控制区提供 0.1× 步进菜单。图片、采集、PS5 不改变源速度，按钮可见但不可用。导出保持原速。

沿用共享 EngineController / EnhanceGraph / 音频所有者。文件变速经显式 seek 边界清理旧呈现队列、重置历史、重建音频重采样器并锚定当前位置，暂停仍保持暂停。无音轨时单调时钟按倍率前进；有音轨时 WASAPI 输出帧通过同一重采样比例映射回原始媒体 PTS。FG 准入的媒体截止时间换算成真实墙钟预算。源 PTS、字幕和进度条仍使用原媒体时间。

本次复用现有 swresample，不新增 FFmpeg DLL/SDK：音频随速度变调，不提供保持音高，菜单/帮助明确说明。PCM 队列继续以输出帧数限界。稳态不通过反复 seek 实现倍速，仅用户改变倍率时重同步一次。

验收：编译；PCM 变速后样本数/媒体尾时间/有界队列；真实音频设备倍率时钟、暂停/seek；真实 EngineController 有声/无声 .2/1/3 倍时钟与热切换；日常/专业/MINI/全屏按钮可见和菜单选择；新干净包基本播放。实际 NR/SR/FG runtime 缺失时必须标明未执行，不把无增强回归说成模型成功。

状态：实现、构建、PCM/实际GPU与音频时钟、原有音频恢复回归及三模式/全屏真实窗口验证通过。无声/有声3×分别实测2.994×/2.989×。初轮无声3×仅2.825×，定位为逐帧重锚的累计等待；修复稳态保持同一单调锚后通过。完整命令及包验证见 WORKLOG。NR/SR/FG Create/Evaluate 未执行。
